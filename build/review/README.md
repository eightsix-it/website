## Measure example and scope

The example was checked against the American College of Radiology's
[2026 QCDR specification, pages 7–8](https://edge.sitecorecloud.io/americancoldf5f-acrorgf92a-productioncb02-3650/media/ACR/Files/Medicare-Medicaid/MIPS-Measures/2026/2026-QCDR-Measure-Specification-Details.pdf#page=7).
It assumes an eligible adult non-cardiac chest CT with no exclusion or
exception. A qualitative CAC description plus the cardiovascular risk
assessment recommendation illustrates the met pathway. Documented absence can
also meet the measure; silence is distinct from absence. The expandable note
explains exclusions and exceptions. Backend scoring code is not in this
marketing repository.

The advertised scope remains ACRad 44 and MIPS 405, 406, 360, 364. Approximately
802 reports remains a validation-volume statement, never an accuracy rate.
Dashboard values retain their projection disclaimer. No new customer names,
pricing, accuracy claims or performance promises were introduced.
